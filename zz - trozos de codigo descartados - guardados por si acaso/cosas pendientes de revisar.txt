 Las reglas deny de tipo Edit no frenan los comandos Bash. 
 Quitar Bash(*documentacion/*) tiene sentido, porque bloqueaba el git add. 
 Pero ahora Edit(/trabajo/directrices/**) solo detiene las herramientas Edit y Write. 
 Un sed -i lanzado por Bash pasaría, y todos los agentes del bucle tienen Bash. 
 
 El README habla de "reglas de obligado cumplimiento". Para blindarlo de verdad haría falta el sandbox o un hook PreToolUse;
